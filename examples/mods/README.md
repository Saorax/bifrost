# Example content mods

Copy a folder from here into `mods\` in the game's install folder, next to `Brawlhalla.exe`. Create `mods` if it isn't there yet. The game reads them at start-up and writes a report to `Documents\Bifrost\bh-mods.txt`.

| Mod | What it does |
| --- | --- |
| `sample-strings` | Changes the text of the main menu's Offline button |
| `sample-tables` | Adds a teal colour scheme and renames Bödvar on character select |
| `sample-language` | Adds a Pirate language to the Language setting |
| `sample-skin` | Adds a teal and gold Bödvar skin |
| `sample-items` | Adds one of each cosmetic item |
| `sample-legend` | Adds a new legend based on Bödvar |
| `sample-map` | Adds a small map |
| `sample-mode` | Adds King of the Hill |
| `sample-lone-king` | King of the Hill with rules written in code |
| `sample-music` | Replaces the menu and map music |
| `sample-anim` | Stretches Bödvar's hammer idle animation |
